# Project Screenshots Guide

Place actual screenshots of the running application in this folder using the following suggested filenames to match the links in the main `README.md`:

1. `01-storefront.png` - Storefront home page with product catalog, search, and category drawer.
2. `02-chatbot-widget.png` - Floating chatbot widget active with conversational stock queries and quick-reply chips.
3. `03-visual-search.png` - Visual product search in action (drag-and-dropped image with similarity confidence score).
4. `04-recommendations.png` - "Frequently bought together" and similar products section on product details / cart drawer.
5. `05-admin-dashboard.png` - Administration analytics dashboard displaying KPIs, sales charts, and chat conversation volume.

> **Note:** Only commit authentic screenshots captured from your local execution. Do not commit fabricated or mock images.
